# zaidme-portfolio

Static index of [Zaid](https://github.com/zaidme)’s public GitHub projects.

Names, locations, the company field, and project blurbs come from the public GitHub profile and repository descriptions. Live links are the homepages already set on those repositories.

## View it

Open `index.html`, or from this directory:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

Language chips filter the project grid. Repositories tagged with more than one language (Uncle Math is Python and TypeScript) appear under each of those filters.

## Publish

On GitHub: Settings → Pages → Deploy from branch `main` → folder `/ (root)`.
